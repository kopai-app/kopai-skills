# Security policy

This policy covers the `kopai` plugin and the skills in this repository.

## Report a vulnerability

Report it privately, never in a public issue:

- on GitHub, under this repository's **Security** tab, with **Report a
  vulnerability**;
- or by email to <hello@kopai.app>, with "Security" in the subject.

Say which plugin `version` (from `plugins/kopai/.claude-plugin/plugin.json`)
or skill `metadata.version` you used, and how to reproduce the problem.

A problem in Kopai itself, such as the API or the MCP server at
`api.kopai.app`, can be reported the same way.

We do not run a bug bounty program.
